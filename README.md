# Hunmeng Novel

Android-приложение для сайта новелл **[hunmeng-novel.ru](https://hunmeng-novel.ru)**.
Пакет: `com.hunmeng.novel`.

## Что умеет (v0.3.5)

- открывает сайт на весь экран, без адресной строки; вход в аккаунт сохраняется;
- кнопка «назад» на телефоне листает назад по сайту;
- полоска загрузки и экран «Нет подключения» с кнопкой «Повторить»;
- ссылки на Telegram и другие сайты открываются в своих приложениях;
- ссылки на hunmeng-novel.ru (например, из Telegram-канала) можно открыть прямо в приложении;
- иконка — эмблема сайта;
- **автоматическое модальное окно обновления (с v0.3.5):** при запуске и возвращении в приложение
  выполняется проверка официальных GitHub Releases, при появлении новой версии показывается фирменное
  окно с номером версии, списком изменений и кнопками «Позже» / «Обновить». Напоминание после
  «Позже» откладывается на сутки, повторные проверки ограничены 15 минутами; APK скачивается
  только из Releases данного Android-проекта и передаётся системному установщику;
- **уведомления о новых главах (с v0.3):** раз в 3 часа приложение сверяет список глав на сайте
  (`catalog.json`) и главы сериалов в Supabase; о новых главах приходит уведомление, нажатие открывает главу.

## Как получить APK

Каждый push в ветку `main` запускает сборку в GitHub Actions.
Готовый файл появляется в **Releases** репозитория: `HunmengNovel-vX.Y.Z.apk`.
Постоянная ссылка на самую свежую версию (для сайта):
https://github.com/DEXTERITY-maker/hunmeng-novel-app/releases/latest/download/HunmengNovel.apk

## Как выпустить новую версию

1. В `RELEASE_NOTES.md` опиши, что нового — этот текст увидят пользователи в окне обновления.
   Каждый пункт — отдельная строка с иконкой. Маркер в начале пункта выбирает иконку:
   `[new]` (или без маркера) — стрелка «новое», `[test]` — колба, `[safe]` — щит. `**жирный**` работает.
2. В `app/build.gradle.kts` увеличь `versionCode` (на 1) и `versionName` (например, `0.1.0` → `0.2.0`).
Новый APK ставится поверх старого: все версии подписаны одним ключом.
Ключ и пароль хранятся в секретах репозитория (Settings → Secrets and variables → Actions):
`KEYSTORE_BASE64` и `KEYSTORE_PASSWORD`. **Не удаляй и не меняй их**, иначе обновление не встанет
и придётся удалять приложение.

## Сборка вручную

```
./gradlew assembleRelease
```
Нужны JDK 17 и Android SDK (compileSdk 35). Результат: `app/build/outputs/apk/release/app-release.apk`.
